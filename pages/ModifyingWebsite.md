# Ok je comprend comment faire

It's rather easy, to make a new page, we create a .md file (markdown). The .md must start with a YAML header which you open and close with triple dashes --- and inside it needs the title of the page, layout (default or minimal) and then you can specify more stuff according to the documentation [Just the Docs]: https://just-the-docs.github.io/just-the-docs/
